  3. Choose how to sign in. With the Azure CLI, run az login first: Azure resource roles only, no admin needed. With Microsoft sign-in you also get Entra roles and PIM groups.Choisissez le mode de connexion. Avec l'Azure CLI, lancez d'abord az login : rôles Azure uniquement, sans administrateur.   4. For Entra roles and PIM groups, most tenants need a one-time consent from a tenant administrator. A ready-to-send email is in docs/admin-consent.Pour les rôles Entra et les groupes PIM, la plupart des tenants exigent le consentement unique d'un administrateur. Un e-mail prêt à envoyer se trouve dans docs/admin-consent.Entra 角色與 PIM 群組在大多數租用戶中需要租用戶管理員一次性同意。docs/admin-consent 中有可直接寄出的電子郵件範本。
